# Tata-Consultancy-Services-Three-Statement-Model-
Built a fully linked three-statement financial model of TCS standardizing 5 years of annual report data and forecasting 5 years to FY31.
# Overview
- Drove the forecast with 25+ assumptions based on historical ratios, plus supporting schedules for depreciation, working capital, and debt and finance costs.
- Projected revenue rising to Rs. 3.52 lakh crore and EPS from Rs. 136 to Rs. 189 by FY31, presented in a summary dashboard with key metrics (margins, free cash flow, ROE) with charts.
